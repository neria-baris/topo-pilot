# מדריך קצר לבעלים

התיקייה הזו היא **חבילת הוראות**. עדיין אין בה קוד. מודל חזק ("מנצח") בונה את הפרויקט לפיה, עם תתי־סוכנים זולים יותר.

## איך מתחילים

1. פותחים את התיקייה כתיקיית עבודה בסביבת סוכן קוד, למשל Claude Code.
2. נותנים למודל החזק את ההוראה:

   > Follow ORCHESTRATOR_PROMPT.md. Start with §13.

3. המודל ייעצר ויבקש את אישורך בארבע נקודות:

   | נקודה | מתי |
   |---|---|
   | **H1** | אחרי הכיול והרישום המוקדם, לפני כל אימון |
   | **H2** | לפני הרצת האימונים: זמן משוער, והאם להריץ מקומית או בחוץ |
   | **H3** | לפני כל שינוי בהחלטה סגורה |
   | **H4** | לפני כתיבת הממצא ב־README |

## מה כבר מובנה בחבילה

| דרישה | איפה זה מטופל |
|---|---|
| מודל חזק כמנצח, ותתי־סוכנים זולים לבנייה | `ORCHESTRATOR_PROMPT.md` §2–3. טבלת הדרגות היא לפי תפקיד, כך שאפשר להחליף מודלים |
| בנייה ואימות של כל מודול בנפרד; טסטים בלתי תלויים במודולים הקריטיים | §3, ‏`agents/`, ו־`tests/<module>/` |
| OOP, מחלקות מופשטות ורישומים להרחבה | `docs/CONVENTIONS.md` §3 |
| עבודה מקבילית בגלים, בלי התנגשויות כתיבה | `docs/STAGES.md` §1, והמסמך הראשי §4 |
| תיעוד הלוגיקה והנתונים | README לכל מודול, ו־`docs/DATA_SCHEMAS.md` |
| בלי לוגים מנופחים | מצב הפרויקט נשמר רק ב־`state/`, עם מגבלת אורך. דיווחי תתי־סוכנים מוגבלים ל־150 מילה ולא נשמרים |
| מעבר למודל אחר | `docs/HANDOFF.md` |
| טסטים נפרדים | `tools/affected_tests.py` מריץ רק את מה שהשתנה |
| הרצה בלי כרטיס גרפי | ברירת המחדל מניחה שאין GPU. המודל קטן, ולפי הערכה אימון אחד על מעבד רגיל לוקח 15–45 דקות, כך שהשלבים עד E2 צפויים להימשך 2–5 שעות. בשלב S3 נמדדת המהירות בפועל: אם השלב הבא צפוי להימשך עד 8 שעות, הוא רץ מקומית על המעבד. אחרת, מודול `executors` אורז כל אימון בצרור שרץ על GPU חינמי (Colab, ‏Kaggle) או שכור, והתוצאות מיובאות בחזרה עם אימות. ראו `docs/EXECUTION.md` §5 |
| שלבים ונקודות עצירה | E0–E4 ב־`docs/STAGES.md` §3 |
| הרחבות | `docs/EXTENSIONS.md`. אפשר להוסיף אותן בלי לשנות את הליבה |

## ההרחבות

- **X1, אוריינטביליות:**
  - מביוס מול גליל: יש להם אותה הומולוגיה, וההבדל הוא במספר רכיבי השפה.
  - בקבוק קליין ו־RP² מול טורוס וספרה: ההבדל ניכר בהשוואת הומולוגיה מעל $\mathbb{F}_2$ לעומת $\mathbb{F}_3$.
- **X2, איחודי טורוסים:**
  - איחוד זר: אי־ודאות לגבי *איזה עולם*.
  - סכום קשיר: משטח מגנוס 2.
- **X3, חורים בממדים גבוהים:** $S^2$, ‏$T^3$, ‏$S^3$. חישוב H₃ מקורב בלבד, ומסומן ככזה.

תוכנית המחקר המלאה, כולל הנימוקים והספרות, נמצאת ב־`docs/RESEARCH_PLAN_HE.md`.
