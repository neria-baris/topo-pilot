# C2 test plan v1 (job 0100)

**Authority:** `tools/c2_readout/PROTOCOL_C2_v1.md` §13.3 (binding), §13.2, §7, §9.3. Functions, names, shapes and record formats are those of `tools/c2_readout/API.md`; values are in `tools/c2_readout/CONTRACT.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report, not to resolve in a test.

## 1. Rules (§13.3)

- Two independent, clean-context authors, **A** and **B**. They write from the frozen protocol, `API.md`, `CONTRACT.json` and this file only, after the freeze and before any module exists. They may read the reused production code of protocol §13.1 (and the `hashes.reused_extra` files of `CONTRACT.json`). They **never read, list or search `tools/c2_readout/*.py`**.
- They execute nothing. The worker runs the tests in PF (§7 row 2); the coordinator runs the full suite detached (§7 row 0).
- Files: author A writes only `tests/c2_readout/test_a_*.py`, author B only `tests/c2_readout/test_b_*.py`; at most 6 files each, each ≤ 400 lines. `tests/c2_readout/AUTHORSHIP_A.md` and `AUTHORSHIP_B.md` record what each author read, did not read and executed (nothing).
- Corrections only by the file's author. **No formatter is ever run over `tests/c2_readout`** (the implementer formats module files by name only).
- Synthetic fixtures only: no store payload, no scientific history, no checkpoint, no stage run. Tiny `TransformerLM` instances are built in the test from `ModelConfig`. Synthetic stores, registries, mailboxes and project roots live under pytest's `tmp_path`, with `--basetemp` under `X:/Downloads/topo-scratch/<job>/` (outside the project root; the K4b registry trap, §5.3 L6).
- Imports as `API.md` §1 "Test imports". Exact arithmetic (`fractions.Fraction`, `decimal.Decimal`) for every exact claim; Monte Carlo claims carry an explicit tolerance derived from the fixture's n and a fixed seed of the test's own `np.random.default_rng(<int>)`.
- Expected values come from the protocol and from independent computations inside the test (not from calls to the function under test).

## 5. Order and commits

1. The tests are committed before any module file enters the worktree: A's files, then B's files, as separate commits by file name, each with its AUTHORSHIP file.
2. The implementer writes the modules against `API.md`; a test that conflicts with `API.md` or the protocol is reported to the coordinator, never edited by the implementer.
3. PF (§7 row 2) runs the unchanged suites and `tests/c2_readout`; the coordinator's detached full-suite run precedes the code freeze H (§7 row 0).
