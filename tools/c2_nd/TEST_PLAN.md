# C2ND test plan v1 (job 0116)

**Authority:** `tools/c2_nd/PROTOCOL_C2ND_v1.md` (C2ND-DESIGN-v1, sha256 `4381655dc0b1e0f8ce50b48c91c756e5eb8e7fae3d4c8592599ab84368d8f0fd`) §5.1, §8.4, §11.3, §11.4 (binding), with §2–§4, §6, §7 for the expected answers. Names, signatures, shapes and record formats are those of `tools/c2_nd/API.md`; values are in `tools/c2_nd/CONTRACT.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report, not to resolve in a test.

## 1. Rules (§11.4)

- Two independent, clean-context authors, **A** (algebra, statistics, decoy maths) and **B** (models, gates, operations). They write from C2ND-DESIGN-v1 (sha256 above), `API.md`, `CONTRACT.json` and this file only, before any module exists. They may read the reused production code named in `API.md` §17 (`tools/c2_readout` at H″, `tools/c1prime`, `tools/x4_circle_history`, `tools/k4b`, `tools/x6_stage1`, `src`). They **never read, list or search `tools/c2_nd/*.py`**, and never read `00_READ_ME_FIRST*` or `docs/research_summary/`.
- They execute nothing. The coordinator runs the full suite detached (§3 row 0); PF runs it at S1 (§3 row 2).
- Files: author A writes only `tests/c2_nd/test_a_*.py`, author B only `tests/c2_nd/test_b_*.py`; **at most 5 files each, each ≤ 400 lines**. `tests/c2_nd/AUTHORSHIP_A.md` and `AUTHORSHIP_B.md` record what each author read, did not read and executed (nothing).
- Corrections only by the file's author. **No formatter is ever run over `tests/c2_nd`.**
- Synthetic fixtures only: no store payload, no C2 store file, no scientific history, no checkpoint, no stage run, no array under `sealed/`. Tiny float64 `TransformerLM` instances are built in the test from `ModelConfig` (e.g. d_model 32, 8 outputs, so that ker(M) has dimension 23 ≥ 6; `API.md` ND-C33). Synthetic stores, registries, scratch roots and project roots live under pytest's `tmp_path`, with `--basetemp` under `X:/Downloads/topo-scratch/<job>/` (outside the project root; the K4b registry trap, §6.7 L6). Fixtures must not create a directory whose name starts with `test_` inside a synthetic scratch root unless the test is about that exclusion.
- Imports as `API.md` §1 "Test imports". Exact arithmetic (`fractions.Fraction`) for every exact claim; floating identities carry an explicit tolerance (stated below); Monte Carlo claims carry a tolerance derived from the fixture's n and a fixed `np.random.default_rng(<int>)` seed of the test.
- Expected values come from the protocol and from independent computations inside the test, never from the function under test. Decision-rule tests may feed per-model bound dicts `b = {stat: {"mean", "L", "U", "rank_L", "rank_U", "g"}}` built directly (sign patterns), instead of bootstrapping.
- No test file contains the byte string of C2's scope or of a parallel round's scope as a literal where a C2-pattern namespace scan could see it (tests are outside every scanned set, but fixtures written under `tmp_path` that must not hit build the string at run time).
