## 1. Rules

- Two independent clean-context authors, **A** and **B**, neither the implementer. Each reads only the protocol copy, `API.md`, `CONTRACT.json`, this file and the public APIs/documents of reused modules (their `API.md`, `CONTRACT.json`, `TEST_PLAN.md`, protocol copies, signatures and docstrings: `tools/hwsc/API.md`, `tools/hwsb/API.md`, `tools/k4b/PROTOCOL_K4B_v1.md`, `tools/k4b/CERTIFICATE.md`, `tools/c2_nd/API.md`). They **never read, list or search `tools/hwsg/*.py`** nor each other's tests, and never open the public research-summary paths, the blinded paths of CONTRACT `blindness`, any store payload, `hist/**`, `sealed/` or checkpoint.
- Files: A writes only `tests/hwsg/test_a_*.py` + `tests/hwsg/AUTHORSHIP_A.md`; B only `tests/hwsg/test_b_*.py` + `AUTHORSHIP_B.md`; each `.py` ≤ 400 lines. Commit by file name (`test(hwsg): author A …` / `author B …`). **No formatter is ever run over `tests/`.**
- **Synthetic and small only.** No training beyond tiny models (the E4 architecture ≤ 20 steps on ≤ 2,048 rows; tiny models ≤ 200 steps), no real-scope history sampling (real-scope `SeedTree` generators may be created and compared draw for draw, as KG2), no real store read except the hash-checked JSON records named here (stage-A `REPORT.json`, S3 world records, `hwsb-store/HANDOFF.json`, hwsu/hwsd obligation JSON). Real-world builders (`hwsg_oracle.build_process_g`, `hwsb_law.law_bound`) on a `MemoryBackend` store are allowed: they draw nothing.
- **Placement.** Every store, synthetic root and scratch root under pytest `tmp_path`; run with `--basetemp X:/Downloads/topo-scratch/test_hwsg-<job>/pytest`, TEMP/TMP/TMPDIR under `X:/Downloads/topo-scratch/test_hwsg-<job>/`. No test writes under `X:/Downloads/projects/topo-pilot/`; no `.npz`/`.npy` committed; synthetic history files are never named `HIST_*.npz` outside a `test_`-prefixed component.
- **Imports:** insert `REPO/"tools"/"hwsg"` at `sys.path[0]` (`REPO = Path(__file__).resolve().parents[2]`), import `hwsg_config` first, then the aliases of API §0.
- Every test entering `gb.world(...)` uses a `with` block and asserts restoration afterwards. Monkeypatch reused functions with pytest `monkeypatch`.
- Exact claims use `Fraction`; float claims state a derived tolerance. Expected values come from the protocol, CONTRACT and independent computations in the test, never from the function under test.
- Where API.md leaves a detail open, accept every reading consistent with it and mark `# API-AMBIGUITY:`.
- Run: `X:/Downloads/projects/topo-pilot/topo-pilot/.venv/Scripts/python.exe -s -m pytest tests/hwsg --basetemp …` with `PYTHONPATH=<worktree>/src`; a suite over 10 minutes runs detached.
