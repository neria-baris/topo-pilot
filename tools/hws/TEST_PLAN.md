# HWS test plan v1 (job 0118)

**Authority:** `tools/hws/PROTOCOL_HWS_v1.md` §12.1 (the author split), §13 (DR1–DR13), §3, §5, §7. Functions, names, shapes and record formats are those of `tools/hws/API.md`; values are in `tools/hws/CONTRACT.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report, not to resolve in a test.

## 1. Rules

- Two independent, clean-context authors, **A** and **B**. They write from the protocol copy, `API.md`, `CONTRACT.json` and this file, and may read the reused production code of `API.md` §8. They **never read, list or search `tools/hws/*.py`**, and they execute nothing (the implementer runs the suites in preflight).
- Files: author A writes only `tests/hws/test_a_*.py`, author B only `tests/hws/test_b_*.py`; each file ≤ 400 lines. `tests/hws/AUTHORSHIP.md` records what each author read, did not read and executed (nothing). Only a file's own author corrects it.
- **No formatter is ever run over `tests/hws`** (the implementer formats module files by name only).
- Synthetic only: no store payload, no scientific history, no stage run, no sampling of a sweep world beyond what a test names explicitly (exact builders and E3 checks on grid worlds are allowed; they draw nothing). Synthetic stores, artifact stores and project roots live under pytest's `tmp_path`, with `--basetemp` under `X:/Downloads/topo-scratch/<job>/pytest/` (outside the project root; the K4b registry trap).
- Imports: a test inserts `REPO / "tools" / "hws"` at `sys.path[0]` (`REPO = Path(__file__).resolve().parents[2]`), imports `hws_worlds` first, then modules by bare name with these aliases: `import hws_worlds as hw`, `hws_stats as hs`, `hws_oracle as ho`, `hws_exact as he`, `hws_select as hsel`, `hws_driver as hd`, `hws_meter_bind as hm`.
- Exact claims use `fractions.Fraction` (and `decimal.Decimal` where named); Monte Carlo claims carry a tolerance derived from n and a fixed `np.random.default_rng(<int>)` of the test. Expected values come from the protocol and from independent computations inside the test, never from the function under test.
