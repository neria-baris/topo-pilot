# X6ZC test plan v1 (job 0117)

**Authority:** `tools/x6zc/PROTOCOL_X6ZC_v1.md` §14 (test coverage, binding), §3.1, §5, §6, §7 B9, §8, §9, §12, §13. Names, signatures and record formats are those of `tools/x6zc/API.md`; values are in `tools/x6zc/CONTRACT.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report, not to resolve in a test.

## 1. Rules (§14)

- **Authors.** Independent, result-blind, clean-context authors who are not the implementer. They write from the protocol copy, `API.md`, `CONTRACT.json` and this file, and may read the reused production code of `API.md` §16 (`tools/x6_stage1`, `tools/x6_stage0`, `src/topo_pilot`). They never read, list or search `tools/x6zc/*.py`, any store (`x6-stage1-store`, `x6zc-store`), the public research summary, or any X6S1 result. They execute nothing; the implementer runs the tests after the modules exist, and the coordinator runs the affected suites detached.
- **Files.** Exactly three: `tests/x6zc/test_x6zc_core.py`, `tests/x6zc/test_x6zc_decide.py`, `tests/x6zc/test_x6zc_dryrun.py`, each ≤ 400 lines, plus `tests/x6zc/AUTHORSHIP.md` (what was read, not read, executed: nothing). The tests are committed before any module file, by file name, one commit per file. **No formatter is ever run over `tests/x6zc`** (the implementer formats module files by name only). Corrections only by the author.
- **Fixtures.** Synthetic only: no store payload, no checkpoint, no X6S1 stored value other than the constants `API.md` and `CONTRACT.json` name, no stage run. Prefixes are short token tuples built in the test (Π0 = `()`, `(10,)`, `(6, 5, 9)`) or random legal torus walks from the test's own `np.random.default_rng(<int>)`. Tiny models are `TransformerLM(sd.MODEL_CFG)` built in the test. Synthetic stores and project roots live under pytest's `tmp_path`, with `--basetemp` under `X:/Downloads/topo-scratch/<job>/` (outside the project root).
- **Expected values** come from the protocol and from independent computation inside the test (exact `Fraction` arithmetic written by the author; never a call to the function under test). Exact claims use `Fraction`; float claims state their tolerance.
- **Imports** as `API.md` §1 "Test imports".
- Notation below: λ_W2 = (49/50)^18, λ_W1 = (49/50)^8; c = (1, 2, 0), c² = (2, 0, 1) as S3 tuples; "cue vector" = the three cue-normalised entries (tokens 15, 16, 17); δ_z the unit cue vector.

## 6. Order and commits

1. The three test files and `AUTHORSHIP.md` are committed before any module file enters the worktree, one commit per file, by name.
2. The implementer writes the modules against `API.md`; a test that conflicts with `API.md` or the protocol is reported to the coordinator, never edited by the implementer.
3. The affected suites (`tests/x6zc`, `tests/x6_stage1`, `tests/x6_stage0`) run detached with `--basetemp` under `X:/Downloads/topo-scratch/<job>/`; then the dry run (`x6zc_run.py dry`, metered) produces the stage-0 evidence for the freeze review.
