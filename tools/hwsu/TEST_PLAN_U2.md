## 1. Rules

- **Reading rule (both authors).** Read only: `PROTOCOL_HWSU_v1.md`, `API_U2.md`, the phase-1 `API.md`, `CONTRACT_OF.json`, `CONTRACT.json`, this file, the phase-1 `TEST_PLAN.md`, and the public signatures and docstrings of reused modules (`docs/code_index/` pages and the reused source). **Never** read `tools/hwsu/*.py` (phase 1 or phase 2), the other author's tests, `OF_REPORT.json` values, the public research-summary paths, any blinded path (API_U2 §0), track-D round files or reports.
- **Files.** Author A: `tests/hwsu/test_a_u2_*.py` and `tests/hwsu/AUTHORSHIP_A_U2.md`; author B: `tests/hwsu/test_b_u2_*.py` and `tests/hwsu/AUTHORSHIP_B_U2.md`. Each file ≤ 400 lines. Phase-1 tests `tests/hwsu/test_*_of_*.py` are never edited. Never run a formatter over `tests/`.
- **Imports.** `import hwsu_config as uc` first (it sets `sys.path`), then `import u2` (the phase-2 package `tools/hwsu/u2/`, which puts its directory on `sys.path`), then the aliases of API_U2 §0 (`um2`, `uk`, `ureg`, `ug`, `ud`, `udry2`) and the phase-1 aliases. Reused modules by name.
- **Footprint.** No array file, no ArtifactStore artifact and no store write under `X:/Downloads/projects/topo-pilot/`. Use `tmp_path` (basetemp `X:/Downloads/topo-scratch/test_hwsu-<job>/pytest`). No real checkpoint is loaded and no real store is opened, except the read-only checks named "real" below (JSON records and hashes only; never `payload.npz`, `state.pt`, `HIST_*`, `sealed/`, charts' contents).
- **Synthetic models.** Tiny `TransformerLM`-shaped models built in memory (1 layer, d_model 16; or the 4-layer d128 random-init model for readout identities, marked `slow`); never trained on a registered scope.
- **Expected values** come from the protocol and the contracts, never from running the implementation. A disagreement is reported to the coordinator, not resolved in a test.
- **Run.** `X:/Downloads/projects/topo-pilot/topo-pilot/.venv/Scripts/python.exe -s -m pytest tests/hwsu -p no:cacheprovider --basetemp X:/Downloads/topo-scratch/test_hwsu-<job>/pytest`, with `PYTHONPATH=<worktree>/src` and TEMP/TMP/TMPDIR under `X:/Downloads/topo-scratch/test_hwsu-<job>/`. Long suites run detached (> 10 min).
