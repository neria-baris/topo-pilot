# HWSB test plan v1 (job 0161)

**Authority:** `tools/hwsb/PROTOCOL_HWSB_v1.md` §9.1 (the author split), §7 (DRB1–DRB16, DRB13b), §3, §4, §5, §6.4, §8.2. Functions, names, shapes and record formats are those of `tools/hwsb/API.md`; values are in `tools/hwsb/CONTRACT.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report through the coordinator, not to resolve in a test.

## 1. Rules

- Two independent, clean-context authors, **A** and **B**. Each reads only the protocol copy, `API.md`, `CONTRACT.json`, this file and the public APIs of the reused modules of `API.md` §11. They **never read, list or search `tools/hwsb/*.py`** (nor each other's tests), and never open the public research-summary paths. Each records what was read in `tests/hwsb/AUTHORSHIP_A.md` or `AUTHORSHIP_B.md`.
- Files: author A writes only `tests/hwsb/test_a_*.py`, author B only `tests/hwsb/test_b_*.py`; each file ≤ 400 lines. Only a file's own author corrects it. Commit by file name (`test(hwsb): author A …` / `author B …`).
- **No formatter is ever run over `tests/hwsb`.**
- **Synthetic and small only.** No training beyond tiny models of a few steps (the E4 architecture for at most 20 steps on ≤ 2,048 rows), no store payload, no scientific history, no real stage run. Real-world builders (`build_process` on a `MemoryBackend` store, `law_bound` on w0 or w\*) are allowed: they draw nothing. Any w\* sampling in a test uses the DRY streams of a dry plan, in memory or under `tmp_path`.
- **Placement (RC-5).** Every store, artifact store and synthetic project root lives under pytest's `tmp_path`; the suite runs with `--basetemp X:/Downloads/topo-scratch/test_hwsb-<job>/pytest`. No test writes under `X:/Downloads/projects/topo-pilot/`; no `.npz`/`.npy` file is committed.
- Imports: a test inserts `REPO / "tools" / "hwsb"` at `sys.path[0]` (`REPO = Path(__file__).resolve().parents[2]`), imports `hwsb_config` first, then modules by bare name with the aliases of API §0 (`hc`, `hd`, `ht`, `he`, `hl`, `hg`, `hk`, `hdr`, `hdry`, `hm`).
- Exact claims use `fractions.Fraction` (and `decimal.Decimal` where named); floating claims state a tolerance derived from the computation. Expected values come from the protocol, CONTRACT and independent computations written in the test, never from the function under test.
- Where API.md leaves a return detail open, a test accepts every reading consistent with API.md and marks the assumption `# API-AMBIGUITY:` for the coordinator.
