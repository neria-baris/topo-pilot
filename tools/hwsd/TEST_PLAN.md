# HWSD test plan v1 (job 0197)

**Authority.** `tools/hwsd/PROTOCOL_HWSD_v1.md` §12.1 (the author split), §10 (DRD1–DRD14), §2–§9 and §11. Functions, names, shapes and record formats are those of `tools/hwsd/API.md`; values are in `tools/hwsd/CONTRACT.json`. The protocol wins on any conflict. A conflict between this plan and API.md is a contract defect to report through the coordinator, not to resolve in a test.

## 1. Rules

- **Two independent, clean-context authors, A and B.** Each reads only:
  - the protocol copy, `API.md`, `CONTRACT.json` and this file;
  - the public APIs and documents of the reused modules of API.md §14 (their `API.md`, `CONTRACT.json`, `TEST_PLAN.md`, protocol copies, docstrings and signatures; e.g. `tools/hwsc/API.md`, `tools/k4b/PROTOCOL_K4B_v1.md`, `tools/k4b/CERTIFICATE.md`, `tools/hwsb/API.md`).

  They **never read, list or search `tools/hwsd/*.py`**, nor each other's tests. They never copy `tests/hwsc`, `tests/k4b` or `tests/hwsb` code.
- **Never opened** by either author:
  - the public research-summary paths (`00_READ_ME_FIRST*`, `docs/research_summary/`);
  - `hwsc-store/stages/TRAIN/**` (except `OBS_INVENTORY.json`, J1), `hwsc-store/logs/**`, `X:/Downloads/topo-scratch/hwsc-job-*`, `agent-handoff/jobs/0187|0188|0189/review.md`, `hwsc-store/stages/E1/L1.json`;
  - track U's files (`*coord-hws-use-20261101*`, `HWSU-*`, `tools/hwsu/`, `tests/hwsu/`);
  - the stage-B blinded files;
  - any `payload.npz`, `state.pt`, `sealed/`, `hist/**` or `HIST_*.npz` array of a real store.

  The JSON records of API.md §3.1-type identity rows may be read. Each author records what was read in `tests/hwsd/AUTHORSHIP_A.md` or `AUTHORSHIP_B.md`.
- **Files.** Author A writes only `tests/hwsd/test_a_*.py`, author B only `tests/hwsd/test_b_*.py`; each file ≤ 400 lines. Only a file's own author corrects it. Commit by file name (`test(hwsd): author A …` / `author B …`). **No formatter is ever run over `tests/`.**
- **Synthetic and small only.**
  - No real store payload, no real-scope history sampling, no real checkpoint load. Real-scope `SeedTree` generators may be created and compared draw for draw, as in KD2(b), without sampling a history.
  - Real-world builders that draw nothing are allowed: `hwsc_data.build_process_c` on a `MemoryBackend` store, `hwsb_law.law_bound`.
  - Block sampling uses the dry binding (`db.load_table(which="dry", …)`) or an explicit `hwsd-dry-v1/<case>` scope.
  - The only training is the E4 architecture for at most 20 steps on ≤ 2,048 rows, or the tiny model.
- **Placement.** Every store, synthetic root and scratch root lives under pytest's `tmp_path`. The suite runs with `--basetemp X:/Downloads/topo-scratch/test_hwsd-<job>/pytest` and TEMP/TMP/TMPDIR under `X:/Downloads/topo-scratch/test_hwsd-<job>/`. No test writes under `X:/Downloads/projects/topo-pilot/`, and no `.npz`/`.npy` is committed.
- **Imports.** A test inserts `REPO/"tools"/"hwsd"` at `sys.path[0]` (`REPO = Path(__file__).resolve().parents[2]`), imports `hwsd_config` first, then the modules by bare name with the aliases of API.md §0, then the reused modules by bare name.
- **Binding hygiene.** Every test that enters `db.bound_hwsd()` does so in a `with` block and asserts nothing about module state outside it except restoration. Monkeypatching uses pytest's `monkeypatch`.
- **Expected values** come from the protocol, CONTRACT and independent computations written in the test, never from the function under test. Exact claims use `Fraction`; float claims state their tolerance. Where API.md leaves a detail open, a test accepts every reading consistent with it and marks the assumption `# API-AMBIGUITY:`.
- **Run time.** Heavy tests (chart constructions on 512 landmarks, 50,000-draw bootstraps) are marked `@pytest.mark.slow` and still run in J-D1.
