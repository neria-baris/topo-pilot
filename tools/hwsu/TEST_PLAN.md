# HWSU test plan, phase 1 (job 0198; the oracle-only stage OF)

**Authority:** `tools/hwsu/PROTOCOL_HWSU_v1.md` §4 (OF gates), §2.1–§2.3 (pairs and oracle quantities), §5.1–§5.2 (known cases), §8 (blindness, namespace, J8/J10, J9), §9 (DRO1–DRO9), §10, §11. Names, signatures and record formats are those of `tools/hwsu/API.md` (§n below = API section unless marked "protocol"); values are in `tools/hwsu/CONTRACT_OF.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report through the coordinator, never to resolve in a test.

**Phase 1 only.** This plan covers the phase-1 files. Phase 2 appends its sections after §6 (see there); phase-1 test files (`tests/hwsu/test_*_of_*.py`) are never edited in phase 2.

## 1. Rules

- Two independent, clean-context authors, **A** (oracle and estimand side) and **B** (records and registry side). Each reads only the protocol copy, `API.md`, `CONTRACT_OF.json`, this file, and the public APIs and documents of the reused modules of API §11 (their `API.md`, `CONTRACT.json`, `TEST_PLAN.md`, protocol copies, docstrings and signatures). They **never read, list or search `tools/hwsu/*.py`** (nor each other's tests), never copy another suite's test code, and never open: the public research-summary paths (`00_READ_ME_FIRST*`, `docs/research_summary/`); `hwsb-store/REPORT.json`, `hwsb-store/stages/EVAL/`, `hwsb-store/GATES.jsonl`, `hwsb-store/CHART_CONSTRUCTIONS_*.json`, `agent-handoff/jobs/0175/`; `hwsc-store/stages/S8/RESULT.json`, `hwsc-store/SEALED_*.json`, `hwsc-store/stages/S5/VALIDATION_REPORT.json`, `hwsc-store/stages/E1/L1.json`, any TRAIN_RECORD `dev_ce`; any track-D file (`*coord-hws-dyn-20261101*`, `HWSD-*`, `tools/hwsd/`, `tests/hwsd/`, `hwsd-store`, `topo-pilot-hwsd`); any `payload.npz`, `state.pt`, `sealed/` file or `hist/**`/`HIST_*` array of a real store. Each records what was read in `tests/hwsu/AUTHORSHIP_A.md` or `AUTHORSHIP_B.md`.
- Files: author A writes only `tests/hwsu/test_a_of_*.py`, author B only `tests/hwsu/test_b_of_*.py`; each file ≤ 400 lines; no `conftest.py` (each file is self-contained). Only a file's own author corrects it. Commit by file name (`test(hwsu): author A …` / `author B …`).
- **No formatter is ever run over `tests/`.**
- **Synthetic and small only.** No real-scope history sampling (real-scope `SeedTree` generators may be created and compared draw for draw, but no history is sampled from them with scopes `hwsu-of-v1` or `hwsu-v1`), no real store write, no metered run, no model, no checkpoint. Real-world builders that draw nothing are allowed: `hwsb_data.build_process` on `ArtifactStore(MemoryBackend())` with the stage-C masters (in memory), `hwsc_data.process_identity` on it (reads `hws-store/SELECTION.json`, a JSON record). Oracle work on real-world rows uses scope `hwsu-dry-v1` or the tiny world, at most 2,048 rows.
- **Placement.** Every store, synthetic root, synthetic mailbox and git fixture lives under pytest's `tmp_path`; the suite runs with `--basetemp X:/Downloads/topo-scratch/test_hwsu-<job>/pytest` and TEMP/TMP/TMPDIR under `X:/Downloads/topo-scratch/test_hwsu-<job>/`. No test writes under `X:/Downloads/projects/topo-pilot/`. Synthetic history files are named `DRYHIST_*` unless a test checks the `HIST_*` rule itself inside `tmp_path` (which is under a `test_`-prefixed folder).
- Imports: a test inserts `REPO / "tools" / "hwsu"` at `sys.path[0]` (`REPO = Path(__file__).resolve().parents[2]`), imports `hwsu_config` first, then modules by bare name with the aliases of API §0 (`uc`, `up`, `uo`, `uof`, `ur`, `us`, `ub`, `um`, `udr`, `udry`); reused modules by bare name after that.
- Exact claims use `fractions.Fraction`; floating claims state a tolerance derived from the computation. Expected values come from the protocol, CONTRACT_OF and independent computations written in the test, never from the function under test. Statistical claims use fixed seeds and a stated bound (4 SE per cell for frequencies).
- Where API.md leaves a return detail open, a test accepts every reading consistent with API.md and marks the assumption `# API-AMBIGUITY:` for the coordinator.
- **Access hooks.** "Never opened" is asserted by monkeypatching `builtins.open`, `io.open`, `pathlib.Path.open`, `Path.read_bytes`, `Path.read_text` and `numpy.load` to record every path, then asserting that the protected paths are absent from the record.
