## 2. `hwsu_pairs.py` (≈200 lines): the exact conditional prefix sampler, blocks, ids, tables (§2.1)

All functions accept `T [N, N]`, `E [N, V]`, `pi [N]`. The kernel functions (§2.1) preserve the input dtype: float64 arrays give float64 results; `dtype=object` arrays of `Fraction` give exact `Fraction` results by the same formulas (`@` on object arrays), so a test can form "the product of the sampler's own kernels, in Fractions" (KS-PAIR).

### 2.1 Kernels

| Name | Contract |
|---|---|
| `stationarity_error(T, pi) -> float` | `float(max_z |(pi @ T)[z] − pi[z]|)` (exact for object input, then `float`) |
| `check_process(T, E, pi) -> None` | raises `C1GateFailure("FAIL_TECHNICAL/SAMPLER", …)` unless: shapes consistent; every `pi[z] > 0`; `stationarity_error(T, pi) <= 1e-12` (`‖πT − π‖∞ ≤ 1e-12`, §2.1 (b)) |
| `time_reversal(T, pi) -> T_rev` | `T_rev[z, z'] = pi[z'] * T[z', z] / pi[z]`, formed as `(pi[None, :] * T.T) / pi[:, None]`. Computed in general; never assumed equal to `T` |
| `backward_messages(T, E, tokens, suffix_len=4) -> beta` | `tokens [n, L]` (int), `L ≥ suffix_len + 1`, `P = L − suffix_len`. Returns `beta [n, N]` = β_P with β_L ≡ 1 and, for t = L−1 down to P (1-based; `tokens[:, t]` is w_{t+1}), `beta_t = (E[:, tokens[:, t]].T * beta_{t+1}) @ T.T`, i.e. β_t(z) = Σ_{z'} T[z, z'] E[z', w_{t+1}] β_{t+1}(z'). β_P(z) = P(w_{P+1..L} | z_P = z). No rescaling |
| `bridge(pi, beta) -> [n, N]` | `w = pi[None, :] * beta`; rows divided by their row sums (`w / w.sum(axis=1, keepdims=True)`); a zero or non-finite row sum → `C1GateFailure("FAIL_TECHNICAL/SAMPLER", "impossible suffix")` |
| `prefix_kernels(T, E, pi, suffix_row, prefix_len) -> dict` | one row (for exact tests): `{"beta": backward_messages(T, E, row[None, :])[0], "bridge": bridge(pi, beta[None])[0], "T_rev": time_reversal(T, pi), "E": E}`, where `row = [0]*prefix_len + list(suffix_row)` (prefix entries are not read). The implied law of the prefix given the suffix is `P(w'_1..w'_P | s) = Σ_{z_1..z_P} bridge[z_P] · Π_{t=1}^{P} E[z_t, w'_t] · Π_{t=2}^{P} T_rev[z_t, z_{t−1}]` |

### 2.2 The sampler (protocol §2.1 step 2, `hwsu_pairs.sample_prefix`)

| Name | Contract |
|---|---|
| `sample_prefix(T, E, pi, arm1, rng, suffix_len=4) -> arm2` | `arm1 [n, L]` integer tokens (L ≥ suffix_len + 1; real use L = 32), rows already in arm-1 sequence-id order (S2). `check_process(T, E, pi)`. `P = L − suffix_len`; `beta = backward_messages(T, E, arm1, suffix_len)`; `B = bridge(pi, beta)`. Draws, **in this frozen order** from `rng` (a `numpy.random.Generator`): (1) `u = rng.random(n)`; `z = sampler._draw(sampler._cumulative_rows(B), np.arange(n), u)` (z_P); (2) for t = P, P−1, …, 1: `arm2[:, t−1] = sampler._draw(cumE, z, rng.random(n))` with `cumE = sampler._cumulative_rows(E)`; then, **only if t > 1**, `z = sampler._draw(cumR, z, rng.random(n))` with `cumR = sampler._cumulative_rows(time_reversal(T, pi))`. Total uniforms: `n · (1 + P + (P − 1))` (= 56n at L = 32). (3) `arm2[:, P:] = arm1[:, P:]` (suffix copied bitwise). Returns `arm2` with `arm1`'s dtype and shape. Row i of `arm2` is paired with row i of `arm1`; nothing is sorted. `sampler` is `topo_pilot.dataset.sampler` (its private `_cumulative_rows`/`_draw` are allowlisted: a zero-probability column is never drawn) |
| `suffix_equal(arm1, arm2, suffix_len=4) -> np.ndarray[bool]` | per row: `arm1[i, L−suffix_len:]` equals `arm2[i, L−suffix_len:]` bitwise (OF-1 (i)) |

- **D-0 (file names).** The task file names the phase-1 documents `API.md`, `TEST_PLAN.md` and `CONTRACT_OF.json`; the protocol (§4.1, §11.1) calls the first two `API_OF.md`/`TEST_PLAN_OF.md` and reserves `API.md`/`TEST_PLAN.md` for phase 2.
