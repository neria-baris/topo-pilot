# HWSC test plan v1 (job 0176)

**Authority:** `tools/hwsc/PROTOCOL_HWSC_v1.md` §10.1 (the author split), §7 (DRC1–DRC14), §3, §4, §5, §6, §8, §9. Functions, names, shapes and record formats are those of `tools/hwsc/API.md`; values are in `tools/hwsc/CONTRACT.json`. The protocol wins on any conflict; a conflict between this plan and `API.md` is a contract defect to report through the coordinator, not to resolve in a test.

## 1. Rules

- Two independent, clean-context authors, **A** and **B**. Each reads only the protocol copy, `API.md`, `CONTRACT.json`, this file, and the public APIs and documents of the reused modules of `API.md` §10 (their `API.md`, `CONTRACT.json`, `TEST_PLAN.md`, protocol copies and docstrings/signatures, e.g. `tools/k4b/PROTOCOL_K4B_v1.md`, `tools/k4b/CERTIFICATE.md`, `tools/hwsb/API.md`, `tools/c2_nd/API.md`). They **never read, list or search `tools/hwsc/*.py`** (nor each other's tests), never copy `tests/k4b` or `tests/hwsb` code, and never open the public research-summary paths, `hwsb-store/REPORT.json`, `hwsb-store/stages/EVAL/`, `hwsb-store/GATES.jsonl`, `hwsb-store/CHART_CONSTRUCTIONS_*.json`, `agent-handoff/jobs/0175/`, or any `payload.npz`, `state.pt`, `sealed/` or `hist/**` array of a real store. `hwsb-store/HANDOFF.json` may be read. Each records what was read in `tests/hwsc/AUTHORSHIP_A.md` or `AUTHORSHIP_B.md`.
- Files: author A writes only `tests/hwsc/test_a_*.py`, author B only `tests/hwsc/test_b_*.py`; each file ≤ 400 lines. Only a file's own author corrects it. Commit by file name (`test(hwsc): author A …` / `author B …`).
- **No formatter is ever run over `tests/`.**
- **Synthetic and small only.** No training beyond tiny models of a few steps (the E4 architecture for at most 20 steps on ≤ 2,048 rows), no real store payload, no scientific history, no real stage run, no real-scope history sampling (real-scope `SeedTree` generators may be created and compared draw for draw, as in KC7, but no history is sampled from them). Real-world builders (`hwsb_data.build_process` on a `MemoryBackend` store, `hwsb_law.law_bound` on w0 or w\*) are allowed: they draw nothing. Block sampling in a test uses the dry binding (`load_table(which="dry", …)`) or an explicit DRY scope.
- **Placement (RC-13).** Every store, artifact store, synthetic project root and synthetic scratch root lives under pytest's `tmp_path`; the suite runs with `--basetemp X:/Downloads/topo-scratch/test_hwsc-<job>/pytest` and TEMP/TMP/TMPDIR under `X:/Downloads/topo-scratch/test_hwsc-<job>/`. No test writes under `X:/Downloads/projects/topo-pilot/`; no `.npz`/`.npy` is committed. Synthetic history files in tests are never named `HIST_*.npz` unless they sit under a `test_`-prefixed component (the C2ND row-9 trap); prefer `tmp_path` inside the `test_hwsc-<job>` basetemp, which already has that prefix.
- Imports: a test inserts `REPO / "tools" / "hwsc"` at `sys.path[0]` (`REPO = Path(__file__).resolve().parents[2]`), imports `hwsc_config` first, then modules by bare name with the aliases of API §0 (`cc`, `cb`, `cd`, `cr`, `ck`, `cg`, `cdr`, `cdry`, `cm`); reused modules by bare name after that.
- Every test that enters `cb.bound_stage_c()` does so in a `with` block and asserts nothing about module state outside it except restoration. Tests that monkeypatch reused functions use pytest's `monkeypatch` (restored automatically).
- Exact claims use `fractions.Fraction`; floating claims state a tolerance derived from the computation. Expected values come from the protocol, CONTRACT and independent computations written in the test, never from the function under test.
- Where API.md leaves a return detail open, a test accepts every reading consistent with API.md and marks the assumption `# API-AMBIGUITY:` for the coordinator.
